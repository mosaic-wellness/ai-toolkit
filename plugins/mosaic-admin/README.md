# mosaic-admin — DEPRECATED

This plugin has been merged into **kai**. Install kai instead:

```
/plugin marketplace add mosaic-wellness/ai-toolkit
/plugin install kai
```

Then run `/kai migrate` to copy over your tokens and see the `/mosaic-admin → /kai admin` command mapping.

All former `/mosaic-admin` capabilities live under `/kai admin` (page configs, widgets, experiments) and `/kai habit` (habit trackers — new in kai 1.2.0). The `admin-essentials` and `habit-essentials` skills auto-activate when you mention PDP / widget / experiment / habit work, so most users don't need a slash command at all.
