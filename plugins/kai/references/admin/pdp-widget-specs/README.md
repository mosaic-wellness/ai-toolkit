# PDP Widget Specs (Bundled)

This directory holds the Mosaic Wellness PDP widget specification — every widget type
that can appear on a Product Detail Page, the narrative codes that classify them, the
shared primitives (header / layout / Media / CTA / SliderConfig), the action catalog,
the two PDP enrichment pipelines, and the request lifecycle that delivers a PDP to a
client.

It is bundled into the **kai plugin** so the plugin works for users who don't have
`mosaic-meta-repo` checked out locally. The canonical, authoritative source is
`mosaic-meta-repo/docs/specs/pdp-widgets/`; this directory is a verbatim snapshot.
See [`_provenance.md`](_provenance.md) for the source SHA, sync timestamp, and refresh
instructions.

## Quick navigation

| Surface | Doc |
| --- | --- |
| `narrative-index.md` | widget → narrative role + edit-safety lookup |
| `widget-catalog.md` | master table of all 122 widget types with PDP relevance |
| `widgets/_conventions.md` | the 12 narrative codes |
| `widgets/_common.md` | header / layout / Media / CTA / SliderConfig primitives |
| `widgets/<TYPE>.md` | per-widget field tables, examples, gotchas |
| `actions.md` | 41 action types usable inside any widget |
| `architecture.md` | request lifecycle |
| `pipeline.md` | the two PDP pipelines |
| `widget-index.json` | machine-readable widget index (generated by `scripts/build-widget-index.mjs`) |

## How to use this bundle

- **Authoring or auditing a widget:** open `widgets/<TYPE>.md` and read alongside
  `widgets/_conventions.md` + `widgets/_common.md`.
- **Picking a widget for a narrative slot:** start at `narrative-index.md`.
- **Understanding what shapes a PDP response:** read `architecture.md` then
  `pipeline.md`.
- **Looking up an action used inside a widget CTA:** see `actions.md`.

## Do not hand-edit

Files in this directory are copied verbatim from the meta-repo. To change a spec,
edit it in `mosaic-meta-repo/docs/specs/pdp-widgets/` and re-run
`scripts/sync-pdp-widget-specs.sh` from the kai plugin root. The sync script will
overwrite local edits.
