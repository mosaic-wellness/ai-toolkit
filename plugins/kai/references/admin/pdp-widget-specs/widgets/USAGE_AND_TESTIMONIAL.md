# `USAGE_AND_TESTIMONIAL`

> Combined "How to use" + customer testimonial section. Compact layout for narrow
> brand themes.

## Identity

- type — `USAGE_AND_TESTIMONIAL`
- headerSupported — true · layoutSupported — true · PDP relevance — ✓
- **Narrative role** — `STORY` — combined how-to-use + voice quote.

### Edit-safety

🟢 `title`, `subtitle`, voice quote in `content` (when no new claims).
🟡 dosage / timing language; `content` if asserting a health claim.
🔴 `section`, `media` slot.
